## 등록과 켜기 순서

1. 각자 사진을 공유 폴더에 올리고 `eval/items/manifest.yaml`의 `items`에 한 줄씩 적는다.
   ```yaml
   items:
     - {id: null, category: person, expected_path: animated, maker: 최호준, file: p01.jpg, note: 막대 사람}
   ```
2. 평가 담당이 일괄 등록한다(T164). 등록되면 `id`가 채워진다.
   ```bash
   cd api && npm run ops:eval-items -- import --manifest ../eval/items/manifest.yaml --dir <사진 폴더> --by <평가 담당 이메일>
   npm run ops:eval-items -- status --manifest ../eval/items/manifest.yaml
   ```
3. S11 모델 평가에서 M1·M2·M3·M5 후보 버전마다 [평가 요청] → 보고서 → 판단(통과 + 근거, 기준값 U5가 없으니 1차는 사람이 판단) → [승격].
4. 승격하면 p1에서 켜진다(새 작업부터).
