# 모델 완주 증거 — 사진 한 장이 결과까지 (p1.sumzip.com)

> 외부 평가(2026-09-30): "사진 → 판정 → 움직임 또는 대체 결과 → 보호자 확인의 완주 사례와 처리 시간 · 실패 이유가 있어야 모델 서빙 프로젝트로 설득력이 생긴다."
> p1은 카카오 로그인만 열려 있어(메일 가입 꺼짐, D36) 세션이 시험 계정을 만들 수 없다 — **팀원이 카카오로 로그인해 팀원이 직접 그린 그림으로 돌린다**(실제 아동 사진 · 그림 금지, G20). 그림은 이진우 시연 세트(역할분담 6번)를 쓴다.

## 돌릴 두 건

| 사례 | 넣을 그림 | 기대 흐름 |
|---|---|---|
| A. 움직임 성공 | 팔다리가 떨어진 사람 그림(흰 종이, 굵은 선) | 올리기 → 바로 걸림(원본 액자) → 판정 "움직임 제안" → 움직임 질문 [예] → M3 움직임 → 결과 확인 [좋아요] → 움직이는 그림으로 바뀌어 걸림 |
| B. 대체(낮춤) | 사람이지만 팔이 몸에 붙은 그림, 또는 집 · 꽃 그림 | 판정이 움직임을 제안하지 않거나(M2 · M4), 움직임 품질 미달 → 2.5D 또는 원본 액자로 낮춤 — 낮춤 이유가 기록되는지 |

## 사례마다 남길 것

| 항목 | 어디서 | 적는 값 |

## 판정 기준(명세 SC)

- 움직임 경로: 확정부터 확인 대기까지 p95 3분 이내(잠정) — 한 건이면 그 값만 적고 p95라고 부르지 않는다.
- 원본 액자 경로: 30초 이내(잠정).
- 인프라 장애가 "모델 낮춤"으로 기록되면 실패.
- 원본이 바뀌면 실패.
