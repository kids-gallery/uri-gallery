## 4. 되돌리는 방법

`*.bak` 사본 대신 **수정 하나 = 커밋 하나**로 남겼다(저장소 이력이 사본 역할, 공유 폴더에 사본 파일을 흩뜨리지 않음).

| 되돌릴 것 | 명령 |
|---|---|
| A11 문서 화면 | `git revert 40a5cf2` → `pm2 restart model-api` |
| A3·A4 상태 경로 | `git revert 5138aad` → `pm2 restart model-api` |
| A6 포트 | `git revert bae76c0` → `pm2 restart torchserve` |

되돌린 뒤 같은 방법으로 확인: `curl -s -o /dev/null -w '%{http_code}' https://p1.sumzip.com/v1/models/health`(되돌리면 405) · `ops/checklist/check-ports.sh`(되돌리면 FAIL 4).
의존성 고정: model-api는 `serving/requirements.lock`(`--require-hashes`) 그대로 — 이번 수정에 새 패키지 없음.
