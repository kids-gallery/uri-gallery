| 단계 | 쓴 것 | 설정 |
|---|---|---|
| 분리 | M1 BiRefNet(위와 같음) | 원본 전체(3024×4032)를 그대로 넣음 → 한 장 31~82초 |
| 종류 판정 | **M2 OpenCLIP** — `laion/CLIP-ViT-B-32-laion2B-s34B-b79K` 리비전 `1a25a44`, open_clip 2.26.1, MPS | 제로샷 4종(사람·동물·집·사물) + 태그 어휘. 어댑터 `m2_openclip.py`. 원본 전체로 판정 |
| 관절 | **M3 Animated Drawings** — TorchServe 0.12(127.0.0.1:9561), `.mar` 2종(릴리스 v0.0.1) | 검출기 → 자세 추정(COCO 17점). 어댑터 `m3_joints.py`(긴 변 1000px로 줄여 보냄) |

### 시험 B. 사람 빼기 (적합성검토 §6-3)

| 단계 | 쓴 것 | 설정 |
|---|---|---|
| 사람 찾기 | **torchvision Mask R-CNN ResNet50-FPN v2**(COCO 학습 가중치 `maskrcnn_resnet50_fpn_v2_coco-73cbd019`, 177MB — 임시 폴더에 받고 삭제). torch 1.13.0 · torchvision 0.14.0(M3 전용 환경) | 긴 변 1024로 줄여 넣음, `person` 점수 0.7 이상, 마스크 0.5 이상, 6픽셀 팽창 |
| 빼기 | numpy · scipy 1.10.0 `ndimage` | M1 마스크 − 사람 마스크 → 가장 큰 덩어리만 남기고 구멍 메움 |
| 판단 | — | 사람 분할이 **손에 든 물건까지 사람으로 칠해** 몸 앞의 작품이 사라짐 |

채택 모델이 아니다. 서비스에 넣으려면 라이선스 확인(BR-MDL-07)과 모델 표 추가(REF)가 먼저 필요하다.

### 시험 C. 종이 모서리 찾기 (적합성검토 §7-2)

| 단계 | 쓴 것 | 설정 |
|---|---|---|
| 종이 후보 | **OpenCV 4.6.0** HSV 변환 | 채도 < 60, 밝기 > 150인 영역을 종이로 봄 → 닫힘 연산(25×25) |
| 사각형 | `findContours` → `convexHull` → `approxPolyDP`(둘레의 3%) | 넓이 8% 이상이고 꼭짓점 4개면 원근 보정(`warpPerspective`) |
| 판단 | — | 흰 벽·밝은 바닥이 더 크고 밝아서 종이 대신 잡힘. 테두리 선 기반 재시도는 중단 |

### 시험 D의 판정 부분 (적합성검토 §7-1)

누끼 파일과 함께, 사각형 안 컷아웃으로 **M2를 다시 판정**했다. 설정은 시험 A와 같고 입력만 원본 대신 컷아웃이다. 판정이 맞은 것이 1~2/6에서 5/6으로 늘었다. 이 판정 결과는 파일로 남기지 않았다.

## 4. 다시 만들 때

- 사각형 좌표(§2 표)와 서비스 어댑터만 있으면 같은 파일을 다시 만들 수 있다.
- 보호자 화면에 "작품 영역 지정"이 들어가면 2단계의 수동 사각형을 보호자 입력이 대신한다. 그다음은 이 문서의 3~5단계와 같다.
- 시험에 쓴 임시 스크립트는 작업용 임시 폴더에 두었다가 지웠다. 저장소에는 넣지 않았다.

## 5. 추가: 평면 그림 "종이째 반듯하게" 따기 — 새 모델 없이 (2026-09-29)

대상은 평면 그림 01·02·03이다. 입력은 §2와 같은 사각형 자르기이고, 긴 변 2048 이하로 줄였다. 새 모델은 쓰지 않았다. 쓴 것은 M1 BiRefNet(기존), OpenCV 4.6.0, numpy다. 결과는 `design/샘플/누끼/종이/`에 있다(git 제외).

| 방법 | 어떻게 | 01 물고기(들고 섬) | 02 활동지(들고 앉음) | 03 지도(책상 위) |
|---|---|---|---|---|
| 1a 마스크 → 4점 근사 | M1 마스크에서 가장 큰 덩어리 → 안쪽 구멍 채우기 → 닫힘 연산(31) → 볼록 껍질 → `approxPolyDP`로 4점 → 원근 보정 | **좋음**(오른쪽 엄지 조금) | **좋음** | ✗ 아래쪽 잘림 — M1 마스크가 지도 아래를 놓쳐 모서리를 잘못 잡음 |
| 1b 마스크 → 최소 사각형 | 같은 마스크에 `minAreaRect` | △ 배경 섞임 | △ 위쪽 손·배경 섞임 | ✗ 아래쪽 잘림 |
| 2 사각형 안 테두리 | Canny(40·120) → 팽창 → 윤곽 → 넓이 20% 이상 4점 | ✗ 못 찾음 | ✗ 엉뚱한 영역(초록 머리띠) | **완벽** |
| 3 가장 긴 직선 4개 | HoughLinesP → 가로·세로 가장 바깥 선의 교점 | ✗ | ✗ | ✗ — 가로·세로 한쪽만 잡힘 |
| **자동 선택(최종)** | 후보 1a·1b·2 가운데 **사각형 변이 실제 경계선 위에 놓인 비율**(테두리 지지도)이 가장 높은 것. 넓이 30% 미만 후보는 제외 | **1a** 선택 → 좋음 | **1a** 선택 → 좋음 | **2** 선택 → 완벽 |

- 처음 자동 선택은 "M1 마스크와 겹치는 정도 + 직각 정도"로 골랐다. 마스크 자체가 틀린 03에서 다시 틀렸다. 사진의 실제 경계선으로 고르도록 바꾸자 세 장 모두 맞았다.
- 남은 한계
  - 손이 종이 위를 가린 자리(01 오른쪽 엄지)는 그대로 남는다. 지우면 작품을 바꾸는 셈이라(FR-22) 지우지 않았다.
  - 표본이 세 장뿐이다. 규칙 안의 평가 그림(팀원이 들고 찍은 그림)으로 다시 재야 한다.
