## 막힌 것과 푼 방법

| 문제 | 원인 | 푼 방법 |
|---|---|---|
| 한국 시각 0~9시에 업로드가 503(#129) | DB 트리거가 UTC 날짜로 만든 날을 검사했습니다 | 한국 날짜 기준으로 고치고 경계 시각 시험을 더했습니다(#130) |
| 미술관 입장이 준비 화면에서 멈춤(#131) | 미리 컴파일이 끝나기를 무한히 기다렸습니다 | 8초 뒤에는 입장합니다(#132). 원인 자체는 남았습니다 |
| 실제 모델 시험 중 worker가 13회 재시작(11-03) | 내가 비교용 스택을 겹쳐 띄워 colima 전체 메모리가 부족했습니다 | 멈추고 팀에 알렸습니다. 실제 M1 스택은 하나만 띄우고 `docker stats`를 먼저 봅니다 |
| M1 한 장 28~40초로 발표 수치를 적음(#43) | 맥의 다른 프로세스 부하를 `docker stats`가 잡지 못한 값으로 보입니다(추론) | 다시 재어 17.4~20.1초, 첫 장 29.3초로 고쳤습니다 |
| 서버에서 `db-migrate`가 `EACCES`(#135) | 600 비밀 파일을 번호가 다른 컨테이너 사용자가 못 읽었습니다. 맥과 WSL에서는 드러나지 않았습니다 | `chmod 444 secrets/*; chmod 700 secrets`로 두고 문서에 적었습니다 |
| 리뷰가 찾은 결함 | #123 부조에서 액자로 바꿔도 전시용 판이 남음, #125 고친 그림을 같은 요청 번호로 보냄(신지현 리뷰) | 회귀 시험을 수정 전 코드에서 실패하는 것까지 보고 고쳤습니다 |
