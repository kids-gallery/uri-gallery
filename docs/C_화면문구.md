## 0. 문구 원칙

1. 점수·확률·등급을 말하지 않는다(BR-SUG-02). 제안은 "~해 볼까요?"처럼 다른 선택을 막지 않는다(BR-SUG-03).
2. 발달 평가·감정 해석·아이 비교로 읽히는 말을 쓰지 않는다.
3. 실패를 성공처럼 꾸미지 않는다. 낮춘 결과는 "…로 바꿨어요", 서버 문제는 "낮춘 결과가 아니에요"를 붙인다(BR-FBK-03, G9).
4. 막힘은 **사유 · 해제 주체 · 다음 행동** 세 줄을 빠뜨리지 않는다(C2). 해제 주체가 다른 사람이면 해제 버튼 없이 대안만 준다(§16 규칙 ③).
5. 오류 원문·객체 키·내부 코드를 화면에 쓰지 않는다(BR-PRV-01). 게이트 번호(G번호)만 블록 제목 옆에 작게 둔다.
6. 한국어 해요체. 이모지·느낌표 없음. 토스트 없음.
