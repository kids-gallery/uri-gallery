## 고칠 순서 제안(재고 뒤, 한 번에 하나)

1. **C2 거짓 200** — p1 nginx에 `location /model-api/` 추가(없으면 404, 있으면 아래 2로 연결). 다른 팀도 같은 증상.
2. **수업 규격 층** — model-api에 `/model-api` 접두 얇은 층: `/health`(모델 상태 → 200/503·loading) · `/predict`(M2 classify 동기, label·score·model_version, TAU 미만 판단보류) · `/predict/batch`(상한 32) · `/metrics`(다섯 숫자) · `/docs`. 수업본 bench.py·metrics.py는 md5 그대로 가져옴. **설계서 먼저**(SD_04·contracts·plan) — 절대 규정.
3. 측정 P1~P4(bench) → 판단보류 행선지 F1~F4 → 문서 E1·E3·E4·E7·E8 → L1.
