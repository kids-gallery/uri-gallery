# 고객 요구: 올리면 걸리는 미술관 (외부 사용자 관점 · 2026-09-30)

> 보호자처럼 p1을 390px로 끝까지 써 본 피드백을 팀 요구서로 옮겼다. 원문 → §1~§3, 팀 내부 분석(원인 · 담당 · 결정) → §4~§6.
> 정리: 이제민 세션2.

## 1. 지금 겪은 것 (증거: 390px 화면, 시험 계정)

- 책상 위에 비스듬히 놓인 그림 사진을 올렸더니 책상 배경까지 그대로 액자에 걸렸다. 진행 표에는 "분리 완료"라고 나온다.
- 올리기부터 전시까지 5개 화면, 10번 조작이 필요하다(방식 고르기 · 확정 · 결과 확인 · 좋아요 · 제목 · 날짜 · 나이 · 저장).
- 화면에 개발자 말이 보인다: 7단계 상태 칩(접수됨 · 판정 중 · 확정 대기 · 처리 중 · 확인 대기 · 승인됨 · 전시 중), "분리/판정/액자 완료", "승인됨 G12", "전시 조건 G12", "[X] 결과 확인 완료", "잘라 낸 작품", "2.5D 입체 부조", "house.png - 0.0MB", "JPEG - PNG - HEIC". "만들기 시작했어요"와 "완료"가 한 화면에 함께 나온다.
- 전시되는 순간이 "전시에 걸렸어요 · 전시 보기" 글자 한 줄뿐이다. 그림이 벽에 걸리는 장면이 없다.
- 미술관 밖(올리기 · 관리)은 일반 웹사이트 모습이다. 위쪽 메뉴 5개, 이메일, 로그아웃이 늘 떠 있고, 표와 칩으로 된 관리 도구처럼 보인다. 회랑은 평면 도형이라 좁게 느껴진다.

좋아진 것: 입장 → 금빛 회랑 → 갈림길 → 전시실로 걷는 흐름, 마지막으로 본 방에서 다시 시작, [건너뛰기], 액자를 누르면 크게 보기 + 아이의 한마디 + 전시 해설(가장 감동적인 부분).

## 2. 고객이 원하는 경험

1. [작품 올리기] → 사진 찍기 · 고르기 → 끝. 보호자가 고르거나 입력할 것 없이 진행된다.
2. 그림 부분만 자동으로 잘리고 반듯하게 펴진다. 결과가 이상하면 [자르기 고치기]로 손가락으로 모서리를 맞춘다. 전시 뒤에도 고칠 수 있다.
3. 기다리는 동안 그림이 액자에 담기는 장면을 본다. 끝나면 회랑으로 옮겨져 벽에 걸리는 장면이 나온다(진열대에 놓이는 입체 작품도 같은 방식).
4. 걸린 뒤 "움직이게 만들어 볼까요?" 같은 권유가 뜬다. 안 눌러도 된다.
5. 제목 · 아이의 한마디는 걸린 뒤 언제든 적는다. 안 적어도 전시된다.
6. 공간은 사진처럼 넓고 사실적이다(아치 천장, 천장화, 대리석 바닥, 깊은 회랑). 아이 그림에만 조명이 비친다.
7. 화면 전체가 미술관이다. 메뉴는 버튼 하나로 접히고, 올리기 · 목록 보기 지름길은 늘 한 번에 닿는다.

## 3. 꼭 지켜 줬으면 하는 것 · 다시 확인할 방법

- 화면에 상태 이름 · 코드 · 모델 단계 · 파일 크기 같은 개발 용어가 나오지 않게. 보호자에게는 "올리는 중 → 액자에 담는 중 → 걸었어요" 정도면 충분하다.
- 휴대폰 데이터로도 장면이 빨리 떠야 한다.
- 실제 미술관 사진 · 이름 · 로고는 쓰지 않는다. 벽화는 저작권이 끝난 작품만 쓴다.
- 움직임 줄이기 설정이면 연출 없이 바로 결과를 보인다.
- 재확인 방법:
  - 같은 책상 사진으로 배경이 잘리는지, 몇 번 조작 만에 걸리는지, 걸리는 장면이 나오는지 본다.
  - 비스듬한 사진 · 어두운 사진 · 손이 나온 사진으로 자동 자르기와 [자르기 고치기]를 본다.
  - 390px · 1440px 전 화면에 개발 용어가 하나라도 보이는지 본다.
  - 느린 인터넷에서 첫 장면이 뜨는 시간을 잰다.
