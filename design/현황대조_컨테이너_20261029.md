# 현황 대조: 기초 설계 · 팀 설계 · 실제 코드(컨테이너 작업 전, 2026-10-29)

컨테이너 작업을 시작하기 전에 세 원천이 서로 맞는지 대조했다. 분류는 셋이다.
- **정본**: 실제 코드와 팀 설계가 같고 그대로 따른다.
- **어긋남**: 한 원천이 낡았다. 어느 쪽이 정본인지 적는다.
- **팀 결정 필요**: 원천에 답이 없거나 이번에 새로 생긴 선택이다.

원천은 다음 넷이다.
1. 기초 설계 v1(2026-09-23~25, 과정 폴더 `model_surving/프로젝트_우리아이미술관/설계도.md` 이전 판과 `유스케이스.md`, `research/첫주판정_엔진재현.md`)
2. 기초 설계 v2(2026-10-20, 같은 `설계도.md`. 35항목 역설계 대조 `research/역설계_대조.md`)
3. 팀 설계(이 저장소 `design/`, `.specify/…/spec.md`·`research.md`, `contracts/`)
4. 실제 코드(이 저장소 `main`)
