# 운영 실행 설계 (#103~#113, 2026-11-04)

사용자가 오늘 착수를 지시했다. 공개 서버 변경은 하지 않고 별도 프로젝트·합성 가족·별도 볼륨으로 검증한다.

## 변경 계약

- #103: 원시 로그 자유 메시지를 버리고 코드 필드의 값도 검사한다. 수집기는 신뢰된 서비스 이름을 붙이며 timestamp/level/service/environment/event/durationMs/httpStatus를 정규화한다. 추적 번호는 검증 후 본문에만 보관하고 인덱스 라벨로 쓰지 않는다. 제삼자·nginx·DB·메일 출력은 수집하지 않는다.
- #104: Docker socket을 연결하지 않는다. 호스트에서 지정 프로젝트의 네 서비스 로그만 읽어 정제한 파일을 공유하고 Alloy는 읽기 전용으로 수집한다. 서비스·환경·수준 필터, 5xx, 합성 수집 heartbeat를 제공한다. heartbeat는 업무 성공과 구분한다. 인증한 Grafana만 loopback으로 연다.
- #105: 모든 시험 컨테이너 json-file 10MB×3 회전, 자원 한도. Loki TSDB 24시간 인덱스·영속 compactor·retention을 설정한다. 24시간은 시험값이며 운영값은 미결정이다. Docker 로그·버퍼·Loki 디스크 합계의 하드 상한이 아니므로 용량 지표와 잔여 공간 점검을 병행한다.
- #106: 로컬 점검기는 DB 준비·워커 상태·큐 대기·수집 heartbeat를 검사하고 연속 실패/복구 전이를 JSON으로 남긴다. 웹훅은 설정한 경우에만 보내며 실제 운영 채널은 별도 결정한다. 앱과 같은 PC 밖의 감시는 후속 구성이다.
- #108: UAM_ENV=production은 가짜 모델·개발 활성화를 시작 시 거부한다. 앱은 HTTPS·보안 쿠키·SMTP와 충분한 비밀 값을 확인한다. 기존 개발 실행은 유지한다. 시험 Compose는 loopback, 새 프로젝트·볼륨·이미지·비밀을 사용하고 root 비밀번호를 분리한다.
- #107/#113: 백업은 쓰는 서비스를 정지한 뒤 DB dump와 작품·워커 상태를 같은 정지 구간에 저장하고 체크섬과 버전을 기록한다. 복원 대상은 새 격리 프로젝트만 허용한다. 복원 후 세션 무효화·작업 lease 만료 처리·백업 이후 삭제 이력 재적용이 끝나기 전에는 외부 공개하지 않는다. 보관 기간·삭제 책임자·RPO/RTO는 승인 전 제안이다.
- #109/#110: 기존 임시 소켓 DB 회귀 시험 및 새 합성 스택으로 가족 간 접근·파일 보존·워커 중단·재접속을 검증한다. 가짜 모델의 결과를 실제 모델 검증으로 표현하지 않는다.
- #111/#112: 배포·복원 검증은 커밋/이미지 ID/모델/설정 이름과 함께 저장한다. 비밀 값은 기록하지 않는다. 비용은 실측 바이트/시간/자원과 단가 입력으로만 산정하며 다른 팀원의 인수인계 검증은 실제 수행 후 기록한다.

## 완료 판정

코드, 로컬 시험, 컨테이너 실연결, 정책 결정, 다른 팀원 검증을 각각 표시한다. 일부 표본 통과로 11개 이슈를 한꺼번에 닫지 않는다.
